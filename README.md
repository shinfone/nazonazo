# 魔法の監獄からの脱出

小学生向けの、絵を見て考える謎解きゲームです。`index.html` をブラウザーで開くと遊べます。追加のライブラリーやサーバーは必要ありません。

タイトル画面からストーリーモードかフリープレイを選べます。ストーリーモードでは、金髪ツインテールの魔法少女ルナといっしょに、やさしい・むずかしい・激ムズの3ステージを順番に攻略します。各ステージは全3問で、全問正解すると次へ進みます。失敗してもそのステージから再挑戦でき、最終ステージをクリアすると脱出エンディングが表示されます。

フリープレイでは難易度を選び、そのコースの10問からプレイごとに重複なしでランダムに3問が選ばれます。

- **やさしい**：これまでの10問を出題
- **むずかしい**：順序の推理、折り紙、道すじ、箱のことばなど新しい10問を出題
- **激ムズ**：複数の手がかりを組み合わせる推理や、図形・道すじの数え上げなど新しい10問を出題

- ストーリーモードは各ステージ3問すべて正解するとクリア
- フリープレイは3問すべて正解すると「ゲームクリア！」
- 0問正解だと「ゲームオーバー」
- 1～2問正解だと「ゲームオーバー」「おしい！」と表示
